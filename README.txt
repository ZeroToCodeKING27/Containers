HOW TO PREVIEW
Open index.html in a modern browser. All pages share a responsive navigation bar and orange/white visual theme.

PUBLISHING
Upload the complete scentsational-website folder to a static website host (for example Netlify, Cloudflare Pages or your existing web host). Keep all files in the same folder so local images and page links work. Connect your domain after publishing.
